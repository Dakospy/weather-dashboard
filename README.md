# Weather Dashboard

A simple, responsive weather dashboard that fetches data from the public Open-Meteo API.

## Features
- Search for weather by city
- See current conditions, humidity, wind, and pressure
- View a 7-day forecast
- Clean, mobile-friendly UI

## Tech Stack
- React
- Vite
- Open-Meteo API

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Notes
- This app uses a public weather API and does not require an API key.
- The app defaults to London on first load.
